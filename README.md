# Simulation d'une chaîne de Markov appliquée à la roulette

## Présentation

Ce projet a été réalisé dans le cadre d'un travail de maturité. Il propose une application développée en Python permettant de simuler l'évolution du capital d'un joueur à la roulette à l'aide d'une chaîne de Markov.

L'application permet de visualiser différentes simulations, d'étudier leur comportement moyen et d'analyser statistiquement les résultats obtenus.

---

## Fonctionnalités

- Simulation de plusieurs parties de roulette.
- Paramètres entièrement personnalisables.
- Affichage de l'évolution du capital.
- Calcul de la trajectoire moyenne.
- Analyse statistique des résultats finaux.
- Interface graphique réalisée avec Tkinter.
